# Web1 · Programación Web I (U-tad)

Proyectos de la asignatura Programación Web I, de JavaScript puro a React.

| Misión | Proyecto | Tecnologías |
|---|---|---|
| [M1 · El Despertar del DOM](Mision1/) | **Tres en Raya**: contra la máquina o a dos jugadores, con marcador y modo oscuro | HTML, CSS, JavaScript puro |
| [M2 · Async Odyssey](Mision2/) | **Brawl Dex**: consume la API pública de Brawl Stars con buscador, filtros, ordenación y caché | Vite, JavaScript, `fetch` + `async/await` |
| [M3 · Reactor Core](Mision3/) | **Brawl Dex en React**: la M2 rehecha con favoritos, ficha aleatoria y hooks propios | React 19, `useFetch`, `useLocalStorage` |
| [M4 · Full Contact Forms](Mision4/Mision4/) | **Torneo Brawl**: formulario de inscripción validado y lista sincronizada | React 19, React Hook Form, Zod, TanStack Query |

Cada carpeta tiene su propio README con cómo arrancarla. Las misiones 2–4 se ejecutan con:

```bash
npm install
npm run dev
```
